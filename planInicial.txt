necesito crear una app usando .net como backend y react como frontend, para el diseño usaremos arquitectura hexagonal, tambien usaremos tailwind para la UI. 
La idea es crear una app con login que implemente jwt, tanto para le inicio de sesion como para el refresh token, la clave maestra y las configuracion de tiempo deben ir en applicationsetting de .net. 
debemos usar postgres 18 como base de datos para almacenar los usuarios. debemos tener un register de usuarios, para que un administrador pueda crearlos. 
Debemos tener una pagina de gestion de usuarios. 
las paginas con seguridad seran 3 diferentes, cada una por rol posible un rol especifico para este mvp, puede tener mas de un rol cada usuario. 
Esta app debe ser un solucion .net. 
El backend y el frontend quearan separados en 2 proyectos. Debe tener un diseño responsive. Las grillas de administacion deben tener tablas con paginacion, ordenamiento y busqueda, todo gestionado por el backend. Cuando la sesion este apunto de caducar, se debe enviar un aviso 30 segundos antes para que el usuario decida sis seguir o cerrar la sesion. 
La pagina debe tener un navbar y un sidebar con los menus. 
Los proyectos se desplegaran en un servidor linux con el dominio mvp-usarios-back.example.com y mvp-usuarios-front.example.com, configurados desde un dns en cloudflare. 
Se debe desplegar en docker usando docker compose. Tengo un server con traefik como gateway. 
Los usuario usaran el correo como cuenta de acceso. Debe tener la opcion de enviar correos, usaremos smtp de gmail como servidor de correos. 
Se deben verificar la cuenta de correos al momento de crear la cuenta. La pagina debe tener logs, usando log4net. 
Usaremos openspec para el desarrollo, revisar las skills para proceder antes de la creacion, la idea es que esta skill planifique y despues hacemos el desarrollo. 
Cada funcionalidad debe tener un test unitario asociado. Debe tener un gitignore el proyecto. el usuario admin sera admin con clave hasheada "admin". 
Debemos usar solo librerias de codigo abierto con licencia como Apache, BSD, MIT y otra similar, completamente libre. 
Se debe poder guardar una imagen del usuario, para ellos debe existir la opcion de sacar una foto usando la webcam de la misma plataforma. 
El login debe implementar el recaptcha de cloudflare, pero si no esta configurado, no lo debe pedir, solo en caso de que este configurado en la configuracion de .net. 
El login debe tener un ratelimit por seguridad, tambien configurable. La app debe desarrollarse en .net 10.
Debes crear un README.md con las especificaciones de como poner en desarrollo y en produccion.
Usaremos Entityframework para las migraciones de la base de datos, sera codefirst la app.
La app backend debera tener su API con una UI como la de OpenAPI o similar, la que disponga la version actual de .net, todos sus metodos deben esta publicados y comentados para su uso desde una UI.
Debemos registrar en que fecha se creo el usuario, cuado ha hecho login. si el usuario no ha cambiado la contraseña en 1 mes (configurable), al momento del login, se le debera pedir que cambie su contraseña, de lo contrario no puede acceder. 
El login debe tener "Olvido su contraseña?" con el flujo correspondiente, enviando una contraseña temporal al correo, la cual debe ser cambiada luego del primer uso de dicha contraseña.
Debemos tener la posibilidad de caducar los token de sesion de los usuarios, por un usuario especifico o por todos los usuarios, para ello debemos llevar registro de los token emitidos, con un jwt id como dicta el estandard. 
Opcionalmente debemos tener en cuenta que esta app podria correr en multiples instancias en un kubernets.
Cada accion de los usuarios, debe ser registrada en los logs, para una mayor auditoria.
los roles deben ser user-tipo-a user-tipo-b user-tipo-c, cada uno con acceso a una pagina diferente, los roles son solo de ejemplo, ya que en el futuro podre agregar nuevos roles o incluso eliminarlos en una grilla de administracion de role.
debes crear un AGENT.md y un DESIGN.md con lo necesario.
debes  registrar todo nuevo conocimiento en README.md.
debes agregar comentarios del porque se tomo cada decision, comentarios tecnicos de los motivos.
