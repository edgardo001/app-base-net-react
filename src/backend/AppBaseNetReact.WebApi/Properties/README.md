# Properties — Configuración del Proyecto

| Archivo | Propósito |
|---------|-----------|
| `launchSettings.json` | Perfiles de lanzamiento (http, https, Docker) con URLs y variables de entorno |

Perfiles disponibles:
- `http` — `http://localhost:5011`
- `https` — `https://localhost:7011`
- `Docker` — Perfil para contenedor
