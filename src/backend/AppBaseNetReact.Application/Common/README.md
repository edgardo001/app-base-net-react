# Common — Componentes Transversales de la Aplicación

Agrupa los elementos compartidos por toda la capa de aplicación: **puertos** (interfaces), **validadores** y **pipeline behaviors**.

| Carpeta | Propósito |
|---------|-----------|
| `Interfaces/` | Puertos que Infrastructure debe implementar |
| `Validators/` | Reglas FluentValidation para DTOs/Commands |
| `Behaviors/` | Pipeline behaviors de MediatR |
