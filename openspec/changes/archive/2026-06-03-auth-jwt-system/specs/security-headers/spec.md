## ADDED Requirements

### Requirement: Security headers on all responses
The system SHALL add security headers to all HTTP responses.

#### Scenario: X-Frame-Options header
- **WHEN** any HTTP response is sent
- **THEN** X-Frame-Options: DENY SHALL be included to prevent clickjacking

#### Scenario: Content-Type protection
- **WHEN** any HTTP response is sent
- **THEN** X-Content-Type-Options: nosniff SHALL be included to prevent MIME sniffing

#### Scenario: XSS protection
- **WHEN** any HTTP response is sent
- **THEN** X-XSS-Protection: 1; mode=block SHALL be included (legacy defense)

#### Scenario: Referrer policy
- **WHEN** any HTTP response is sent
- **THEN** Referrer-Policy: strict-origin-when-cross-origin SHALL be included

#### Scenario: Permissions policy
- **WHEN** any HTTP response is sent
- **THEN** Permissions-Policy: camera=(self), microphone=() SHALL be included

#### Scenario: Content Security Policy
- **WHEN** any HTTP response is sent
- **THEN** Content-Security-Policy SHALL be included allowing Cloudflare Turnstile scripts and blocking most external resources

### Requirement: Security headers middleware placement
Headers SHALL be set using context.OnStarting() to ensure they are applied even if downstream middleware modifies the response.

#### Scenario: Headers set before response
- **WHEN** an HTTP response is generated by downstream middleware
- **THEN** the SecurityHeadersMiddleware SHALL use context.Response.OnStarting() to set headers
- **THEN** headers SHALL be present in the final response regardless of downstream modifications
